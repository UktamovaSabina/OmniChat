How it works

  1. Classify: a fast AI model labels the question (coding, math, writing, research, image, translation or general).
  2. Score: the router looks up each model's benchmark score for that task.
  3. Route: the highest-scoring model answers. If scores tie, the cheaper one wins.
Demo note: scores are illustrative placeholders, to be replaced with real benchmark data. In this MVP only Claude is connected, so Claude writes every answer; the other providers plug in through their APIs.
